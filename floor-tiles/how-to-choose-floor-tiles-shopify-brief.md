## 4. How people search this topic: Google vs AI assistants

**ChatGPT / Claude / Gemini / Google AI Mode (long, multi-constraint, conversational):** the prompt bundles several attributes and a situation into one request. Typical patterns:

- Follow-ups: "show me pictures", "where can I buy them in the UK", "which is better quality", "option A or B".

Google's AI surfaces are already citing the store mid-conversation.

## 9. Data issues found on the live store (fix before or alongside publishing)

These can confuse buyers, and the article avoids them by quoting only consistent data.

1. **Slip-rating contradictions:** three products state one R rating in the description and another in the spec block:
   - *Statuario Carrara White Matt Anti-Slip 60×120*: spec block **R9**, description **R10**.
   - *Statuario Mercury Grey Matt Anti-Slip 60×60*: spec **R11**, description also mentions R9/R10.
   - *Crystal Blue Marble Effect 30×60 Matt Antislip*: spec **R11**, description also mentions R10.
2. **Missing slip ratings:** only 41 of 410 floor-tile listings show a slip rating in the spec block, and several "anti-slip" tiles have none. Adding the R value to every matt/anti-slip tile would let the article (and Google) state it.
3. **Price outlier:** "Wholesale Marble Effect Porcelain Gloss 60x60cm" is listed at **£1,000** inside the floor-tiles collection. It was excluded from the price table.
4. **Weight field:** the same size shows different "Weight" values (e.g. 13KG vs 29KG for 60×120) with no unit basis (per tile / per box). It was not used in the article.
5. **Script fix:** `extract_serp_dossier.py` read `sitemap_blogs_1.xml`, which lists only the 2 blog index pages, so the cannibalisation check never saw the 140 articles. Its hardcoded product and collection ranges were also stale (one returned HTTP 400). The patched copy in `tools/` reads the live sitemap index instead.
