## 8. Cost-of-retrieval checklist (Koray framework)

- [x] The head term is defined in the first sentence, in copular form, inside the first 14 KB of HTML.
- [x] Every H2 and H3 is a question, and the answer is in the next sentence with nothing in between.
- [x] Each sentence carries one fact. Pronouns across sentences are avoided where they could create coreference errors.
- [x] Facts are repeated in prose **and** in `<table>` with `<caption>` and `<th scope>`, for WebTables-style extraction.
- [x] Units and forms vary: 60×120cm / 600x1200 · m² / per box / per pallet · 0.72m² per tile · 400mm / one third · 9mm.
- [x] Consensus comes first, with honest limits: "no slip rating published", prices carry a date, and the weight is labelled as worked out from density.
- [x] Standards are cited inline at the end of the claim: BS EN 14411, BS 5385-1, ANSI A108.02, the HSE PTV 36 threshold.
- [x] Server-rendered HTML with no JavaScript, and images that are WebP with fixed dimensions.
- [x] The article closes with "Last thoughts on Onyx Diora Gold", naming what the piece proved.
- [x] The writing style differs from earlier posts: a "Short answer" box instead of a bold lead, a spec card with two size columns, a room-verdict table, a break-even H3, and a single supplementary H2 below the border.
